Archive Editor

Edit or delete entries stored in site/archive.json directly on GitHub. This page isn't linked from the site's navigation — bookmark it if you want quick access.

How to create a token (one-time setup)
  1. GitHub → your avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: your account. Repository access: "Only select repositories" → pick your PolicyUpdate.eu repo.
  3. Under Permissions → Repository permissions, set Contents: Read and write. Leave everything else as No access.
  4. Generate, then paste the token below. It starts with github_pat_. Keep it private — anyone with it can edit this repo.
